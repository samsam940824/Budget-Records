# 快速記帳捷徑

用 iPhone 捷徑在幾秒內記一筆帳：選帳戶 → 選分類 → 輸入金額 → 輸入備註。
捷徑每次執行都會讀取網頁上目前的帳戶與分類，所以在網頁新增、改名或封存後，捷徑會自動同步，不需要改捷徑。

```
iPhone 捷徑 ──(Bearer token)──▶ Supabase Edge Function「quick-entry」──▶ records 資料表
```

- 只能寫入 token 擁有者自己的資料。
- 資料庫只存 token 的 SHA-256 雜湊；token 外洩時到「設定 → 快速記帳捷徑」重新產生，舊的立刻失效。
- 封存的帳戶不會出現在捷徑裡。
- 分類清單依最近 90 天使用次數排序：支出分類在前，收入分類（前面有 💰）在後，最後是「↔️ 轉帳」。

## 一次性部署（自架者）

1. 在 Supabase SQL Editor 執行 [`supabase/migrations/0003_quick_entry.sql`](../supabase/migrations/0003_quick_entry.sql)。
2. 部署 Edge Function，並**關閉 JWT 驗證**（捷徑用自己的 token，不是 Supabase 登入憑證）：
   ```bash
   npx supabase functions deploy quick-entry --no-verify-jwt --project-ref <你的 project ref>
   ```
   用 Dashboard 部署的話，到 Edge Functions → quick-entry → Settings，把 **Verify JWT** 關掉。
3. `SUPABASE_URL` 與 `SUPABASE_SERVICE_ROLE_KEY` 由 Supabase 自動提供，不需要另外設定。

## 取得 token

網頁 → 設定 → **快速記帳捷徑** → 產生 token。畫面會顯示 **Token** 與**網址**，token 只顯示這一次。

## 建立捷徑

打開「捷徑」App → 右上角 ＋ → 依序加入下列動作。`〔 〕` 代表從上一步點選的藍色變數。

**讀取選單**

1. **取得 URL 內容**
   - URL：貼上「網址」
   - 展開選項：方法 `GET`；標頭新增 `Authorization`，值為 `Bearer ` 加上你的 token（Bearer 後面有一個空格）
2. **取得字典值**：取得 `accounts` 的「值」，字典選〔URL 的內容〕
3. **從列表中選擇**：提示文字「帳戶」
4. **設定變數**：名稱 `帳戶`，值〔所選項目〕
5. **取得字典值**：取得 `categories` 的「值」，字典選〔URL 的內容〕（第 1 步的結果）
6. **從列表中選擇**：提示文字「分類」
7. **設定變數**：名稱 `分類`，值〔所選項目〕

**轉帳時選轉入帳戶**

8. **文字**：內容放入〔分類〕
   - 「如果」無法直接對從清單選出的變數使用「包含」，先轉成文字才會出現這個條件。
9. **如果**〔文字〕**包含** `轉帳`，在「如果」與「否則」之間加入：
   - **取得字典值**：取得 `accounts` 的「值」，字典選〔URL 的內容〕
   - **從列表中選擇**：提示文字「轉入帳戶」
   - **設定變數**：名稱 `轉入帳戶`，值〔所選項目〕
   - 「否則」底下留空

   繳信用卡費就是轉帳：帳戶選付款的銀行帳戶，分類選「↔️ 轉帳」，轉入帳戶選信用卡。分類名稱不要取含「轉帳」兩個字的名字，以免被當成轉帳。

**輸入金額與備註**

10. **要求輸入**：類型「數字」，提示「金額」
11. **設定變數**：名稱 `金額`
12. **要求輸入**：類型「文字」，提示「備註（可留空）」
13. **設定變數**：名稱 `備註`

**送出**

14. **取得 URL 內容**
    - URL：同第 1 步
    - 方法 `POST`；標頭同第 1 步
    - 要求本文選「JSON」，新增欄位（類型都選「文字」）：

      | 鍵 | 值 |
      |---|---|
      | `account` | 〔帳戶〕 |
      | `category` | 〔分類〕 |
      | `to_account` | 〔轉入帳戶〕 |
      | `amount` | 〔金額〕 |
      | `note` | 〔備註〕 |
15. **取得字典值**：從第 14 步的〔URL 的內容〕取得「**所有數值**」
    - 回應只會有一個鍵：成功時是 `message`，失敗時是 `error`，所以取所有數值就是要顯示的那句話。
16. **顯示通知**：內容〔辭典值〕

最後把捷徑命名為「記帳」。

## 放到鎖定畫面或快捷位置

- **鎖定畫面下方按鈕**（iOS 18 以後）：長按鎖定畫面 → 自訂 → 鎖定畫面 → 點手電筒或相機按鈕旁的「−」移除 → 點「＋」→ 捷徑 → 選「記帳」。
- **動作按鈕**（iPhone 15 Pro 以後）：設定 → 動作按鈕 → 捷徑 → 記帳。
- **背面輕點**：設定 → 輔助使用 → 觸控 → 背面輕點 → 點兩下 → 記帳。

從鎖定畫面執行時，iOS 可能要求先用 Face ID 解鎖才能連網，這是系統行為。

## 常見問題

| 通知內容 | 原因與處理 |
|---|---|
| 捷徑 token 無效，請到設定重新產生 | token 已被重新產生或停用；到網頁重新產生並更新兩個「取得 URL 內容」的標頭 |
| 缺少捷徑 token | 標頭名稱要是 `Authorization`，值要以 `Bearer ` 開頭 |
| 找不到帳戶／分類「…」 | 帳戶可能被封存或改名；重新執行捷徑會拿到最新清單 |
| 金額必須是大於 0 的數字 | 金額輸入 0、負數或超過兩位小數 |
| 記帳時間差一天 | 捷徑以台灣時間（Asia/Taipei）記錄日期 |
